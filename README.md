# Huishouden: versiekanaal

Alleen het versiebestand van de huishouden-app (`versie.json`): versie, datum en de titels van *Wat is er nieuw*. Een installatie van de app kijkt hier één keer per dag of er een nieuwe versie is, zonder iets van de gebruiker mee te sturen. De code zelf staat hier niet; die krijg je met een uitnodiging.

Het adres van `versie.json` verandert nooit.
